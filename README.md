# Student Final Grade Calculator

## Introduction

This project is a C++ application designed to calculate students' final grades based on their homework and exam results.

## Final Grade Formula

Final points = 0.4 * (Average of HW or Median of HW) + 0.6 * Exam

## Features

- Enter student names and surnames.
- Enter homework and exam results.
- Calculate final grades using average or median.
- Generate random homework and exam scores.
- Read student data from Students.txt.
- Sort students by name or surname.
